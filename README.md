
# 🐾 Patas Amigas

## Sobre o projeto

O Patas Amigas é um site desenvolvido para uma ONG fictícia de proteção animal. O objetivo é apresentar os projetos da organização e permitir que pessoas interessadas possam realizar um cadastro para ajudar.

O projeto foi desenvolvido durante as atividades práticas do curso de Sistemas de Informação.

## Tecnologias utilizadas

- **HTML5:** estrutura das páginas e formulários.
- **CSS3:** aparência e organização do site.
- **JavaScript:** navegação SPA, validação e interatividade.
- **localStorage:** armazenamento dos dados no navegador.
- **Git e GitHub:** organização e versionamento do projeto.

## Funcionalidades

- Página inicial com apresentação da ONG.
- Página de projetos.
- Formulário de cadastro com validação.
- Armazenamento local dos dados.
- Navegação SPA utilizando JavaScript.

## Como executar o projeto

1. Clique em **Code > Download ZIP** no GitHub.
2. Extraia os arquivos no computador.
3. Abra a pasta `html`.
4. Abra o arquivo `index.html` no navegador.

Não é necessário instalar bibliotecas ou dependências adicionais.

## Organização dos arquivos

- `html/` — páginas HTML.
- `css/` — estilos do site.
- `js/` — arquivos JavaScript.
- `imagens/` — imagens utilizadas.

## Versionamento

O projeto utiliza uma organização baseada no GitFlow:

- `main` — versão principal.
- `develop` — integração das alterações.
- `feature/` — desenvolvimento de novas funcionalidades.

As alterações são registradas por commits e integradas através de Pull Requests.

## Acessibilidade

O site possui textos alternativos nas imagens, identificação dos campos do formulário e melhorias para navegação pelo teclado.

## Testes

Os testes são feitos manualmente no navegador, verificando a navegação, o formulário e as mensagens de validação.

O projeto não utiliza testes automatizados nem precisa de uma etapa de build.
