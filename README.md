Patas Amigas 🐾

Sobre o projeto

O Patas Amigas é um site desenvolvido para uma ONG fictícia de proteção animal. O objetivo é apresentar os projetos da organização e permitir que pessoas interessadas possam realizar um cadastro para ajudar.

O projeto foi desenvolvido durante as atividades práticas do curso de Sistemas de Informação.

Tecnologias utilizadas

HTML5: estrutura das páginas e formulários.

CSS3: aparência e organização do site.

JavaScript: navegação entre páginas, validação do formulário e interatividade.

localStorage: armazenamento dos dados do cadastro no navegador.

Git e GitHub: organização e versionamento do projeto.

Funcionalidades

Página inicial com apresentação da ONG.

Página com informações sobre os projetos.

Formulário de cadastro.

Validação dos campos do formulário.

Armazenamento local das informações.

Navegação SPA utilizando JavaScript.

Como executar o projeto

Baixe o projeto pelo GitHub, utilizando a opção Code > Download ZIP.

Extraia os arquivos em uma pasta do computador.

Abra a pasta html.

Execute o arquivo index.html em um navegador.

Não é necessário instalar bibliotecas ou dependências adicionais.

Organização dos arquivos

html/ — páginas HTML.

css/ — arquivo de estilos.

js/ — arquivos JavaScript.

imagens/ — imagens utilizadas no site.

Versionamento

Para organizar o desenvolvimento, utilizei uma estrutura baseada no GitFlow:

main: versão principal do projeto.

develop: branch utilizada para reunir as alterações.

feature/: branches criadas para desenvolver funcionalidades separadamente.

As alterações foram registradas por meio de commits e integradas utilizando Pull Requests.

Acessibilidade

O projeto também conta com algumas melhorias de acessibilidade, como textos alternativos nas imagens, identificação dos campos do formulário e destaque dos elementos durante a navegação pelo teclado.

Testes

Os testes são realizados manualmente no navegador, verificando a navegação entre as páginas, o funcionamento do formulário e as mensagens de validação.

O projeto ainda não possui testes automatizados ou uma etapa de build.
